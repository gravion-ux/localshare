# Pro and Support

Maintainer: Priyanshu Kumar Thakur

## Why a paid option exists here

Teams sharing previews repeatedly need stable hostnames and help with tunnel and access setup. The free version below stays complete for local use; nothing in the free core is removed or crippled to force an upgrade.

## Free (this repository)

- Quick Tunnel sharing from the CLI
- Named Tunnel mode with a stable hostname
- Email allow-list and explicit public mode
- Loopback-only origin checks

## Paid / supported option

- Stable preview setup guidance for teams
- Priority support for Named Tunnel and access-policy setup
- Team preview-sharing workflow guidance

Paid features are offered as support, setup help, templates, or a hosted service where stated. They are not hidden gates inside the free code in this repository.
